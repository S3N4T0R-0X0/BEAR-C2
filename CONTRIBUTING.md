# Contributing to BEAR-C2

Thank you for your interest in contributing to **BEAR-C2**!

BEAR-C2 is an **adversary simulation and emulation framework** designed for educational, research, and authorized red-team / adversary simulation purposes only.  
It is inspired by real-world TTPs from Russian, Chinese, North Korean, and Iranian APT groups.

By contributing, you agree to follow the guidelines below and the terms of the [BEAR C2 Educational & Research License](License).

## How Can I Contribute?

We welcome suggestions and contributions in the following areas:

### 1. Bug Reports
- Found a crash, unexpected behavior, or incorrect functionality?
- Contact the project owner and include:
  - Clear description of the problem
  - Steps to reproduce
  - Expected vs actual behavior
  - OS / Python version / relevant environment details
  - Screenshots or logs (if possible)

### 2. Feature Suggestions
- Have an idea that improves adversary simulation realism, usability, or modularity?
- Contact the project owner to discuss it.
- Features should align with the project’s educational and research goals.

### 3. Code Contributions
- Bug fixes
- Improvements to existing modules (listeners, encryption, exfiltration profiles, stagers, GUI, etc.)
- New educational modules or techniques (with proper documentation)
- Documentation improvements
- Code cleanup and readability

### 4. Documentation
- Improving the README
- Writing usage examples
- Clarifying installation or configuration steps
- Adding comments to complex parts of the code

## Code Style

- Follow the existing code style of the project
- Prefer clear and readable code over overly complex solutions
- Add comments for non-obvious logic, especially security-related or protocol-related parts
- Avoid introducing unnecessary dependencies
